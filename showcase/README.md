# Vercel showcase source

Live: https://rohit-project-showcase.vercel.app/

Static portfolio and three frontend demo paths. Banking/library project buttons link to the hosted Base44 app with sign-in and storage; the static /banking/ and /library/ paths remain explicitly labelled UI demos. Amazon is the unchanged production build of the React storefront. The built JavaScript and CSS in assets/ are generated from the amazon-clone repository.

Deploy this directory as a static Vercel project (no build/install command, output directory .). No credentials are required in these files. Backend records remain in Base44, not in GitHub or Vercel files.
