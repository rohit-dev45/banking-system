## Overview
A production-style banking backend built using Spring Boot, designed to handle
high-volume transactions with secure REST APIs.

## Key Features
- Account creation & management
- Transaction processing with validation
- Exception handling & logging
- RESTful API design

## Tech Stack
Java, Spring Boot, Spring MVC, Hibernate, MySQL, Maven, JUnit

## Architecture
- Layered architecture (Controller → Service → Repository)
- Stateless REST APIs
- DTO-based request/response handling

## What I Learned
- Designing scalable REST APIs
- Writing clean service-layer logic
- Handling concurrency & validations
- Optimizing DB queries
